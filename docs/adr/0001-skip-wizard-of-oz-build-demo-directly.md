# Skip Wizard-of-Oz validation; validate via dogfooding and in-market signal instead

**Status:** accepted

The PRD's risk table (§14, risk #1) originally named a manual Wizard-of-Oz protocol as the required first step, with kill criteria defined before starting. We skipped that step and are building the full product per the PRD instead (§15: Phase 1 pipeline slice → Phase 2 loop and screens → Phase 3 production readiness → Phase 4 v2 candidates).

Premise validation isn't dropped, though — it's replaced by two mechanisms that don't require a dedicated pre-build phase: **owner dogfooding** (§13), starting the moment the Phase 1 slice works and continuing through every later phase, since the owner's own profile (fluent-but-lapsed Russian speaker) sits close enough to the target user to give partial signal on latency feel, turn detection, grammaticality, and the repetition wall (§13 "What this covers well"); and **in-market signal** after release — abandonment turn and session-2 return rate, with a weak session-2 return rate treated as the premise failing rather than a retention problem to optimize (§14, risk #1).

**Considered options:** (1) run Wizard-of-Oz as scoped; (2) skip it and build a narrow demo first, just enough to talk to the persona, before committing further; (3) skip it and build the full product, accepting the premise as unvalidated until dogfooding and in-market data arrive. The decision moved from (2) to (3) over the course of discussion, then (3) was sharpened by adding dogfooding and in-market signal as explicit (partial) substitutes for the dropped validation step, rather than leaving the risk wholly unmitigated.

**Consequences:** the premise ("will adults voice-chat with an AI grandmother?") is not validated before most of the build happens, and §13 is explicit about what dogfooding structurally cannot cover — the nervous-learner state and unconscious topic-avoidance are invisible to an owner who already knows the product and isn't nervous using it. Real validation on those specific gaps arrives only with session-2 return rate after release, a late and expensive point to discover the premise was wrong. Also note the STT vendor bake-off (§7.5) originally planned to score against "Phase 0 Wizard-of-Oz recordings" that no longer exist under this decision — §7.5 now specifies deliberate audio collection (record target learners, or buy time with tutoring-platform students) as the replacement source.
