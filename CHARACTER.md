# Character Generation Guide

## Project: AI Language Learning App

## Overview

Create a cast of stylized conversational characters for a premium AI language learning application.

The experience should feel like **FaceTime with recurring people**, not interacting with NPCs or game characters.

These characters will ultimately become:

- Low-poly 3D models
- Animated in Blender
- Exported as GLTF
- Rendered in React Native
- Used for lip-sync, facial expressions, blinking, eye contact, and subtle idle animation.

The artwork produced here is **concept art** for production.

---

# Overall Style

The visual style should resemble **feature animation concept art** rather than flat vector illustrations.

Inspirations:

- Pixar concept art
- DreamWorks character design
- Netflix animated films
- Modern stylized character concept art

Avoid:

- Photorealism
- Anime
- Disney princess style
- Chibi proportions
- Corporate vector illustrations
- Duolingo-style flat graphics

The characters should feel premium, warm, timeless and expressive.

---

# Design Principles

Every character should have:

- Large expressive eyes
- Appealing facial proportions
- Strong silhouette
- Soft facial planes
- Warm color palette
- Friendly smile
- Slightly exaggerated proportions
- Clean shape language
- Simple clothing
- Memorable hairstyle

The personality should be recognizable before reading their profession.

---

# Production Requirements

These illustrations are intended to become production-ready 3D characters.

Design with animation in mind.

Avoid:

- Tiny accessories
- Complex jewelry
- Intricate fabric patterns
- Hair covering the face
- Complex layered clothing

Everything should be simple enough to model and rig.

---

# Framing

Always generate:

Head to upper chest.

The face should occupy roughly 65–70% of the image.

Eye level camera.

Very slight 3/4 angle (5–10°).

Transparent or neutral background.

---

# Lighting

Soft studio lighting.

Warm.

Minimal shadows.

No dramatic rim lighting.

The character should feel approachable.

---

# Facial Features

Prioritize:

- expressive eyebrows
- expressive eyes
- readable mouth
- soft cheeks
- clean jawline
- slightly stylized nose

The mouth should be designed for lip sync.

---

# Clothing

Simple.

Timeless.

Large readable shapes.

No logos.

No text.

No distracting details.

---

# Animation Constraints

These characters will eventually support:

- blinking
- eye tracking
- breathing
- smiling
- laughing
- subtle concern
- curiosity
- thinking
- nodding
- lip sync

Design the face so every feature can move independently.

---

# Character Sheet Layout

Generate a production character sheet containing:

- Hero portrait
- Front view
- 3/4 view
- Side view
- Expression sheet
- Color palette
- Clothing detail
- Hair detail
- Turnaround reference

Do NOT include technical annotations or measurements.

# Consistency Rules

Every character must:

- belong to the same artistic universe
- use identical rendering style
- use identical lighting
- use identical proportions
- use identical framing
- use identical brush style
- use identical level of detail

Only change:

- face
- hairstyle
- clothing
- color palette
- posture
- personality

The viewer should immediately recognize them as members of the same cast.

---

# Final Goal

The finished cast should feel like recurring people the learner develops a relationship with over time.

The user should feel:

> "I'm calling Nona."

instead of

> "I'm opening another lesson."

The emotional goal is familiarity, warmth, and genuine human connection.
